Drop custom artwork here.

  art/<slug>.png        replaces the front cover art
  art/<slug>-back.png   replaces the back panel background (optional)

The slug is the folder name under out/ — e.g. out/hades-ps5/ means art/hades-ps5.png.
`npm run prompts` writes out/prompts.md, which lists the exact filename for each game.

Anything here wins over SteamGridDB and RAWG, and is re-checked on every build.
